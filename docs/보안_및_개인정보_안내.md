# 보안 및 개인정보 안내

AISideQuest는 AI 작업의 **내용이 아니라 상태, 시간, 정제된 표시 정보**만 다루는 것을 원칙으로 합니다.

## 수집하는 정보

| 구분 | 예시 |
|---|---|
| 계정 | GitHub 숫자 ID, login, 표시 이름, avatar |
| 기기 | 기기 이름, plugin 버전, 마지막 연결 시각 |
| AI 작업 | event 종류, 임의 ID, 해시된 session·turn key, 관측 시각, 마지막 폴더명, 고정 목록의 명령 분류 |
| 퀴즈 | 선택 답안, 점수, 통과 여부 |
| 포인트 | 적립 이유, 포인트, 생성 시각 |
| Discover 저장 | 정제된 항목 snapshot, source item ID, 저장 시각 |
| Discover 관심 기술 | 고정 목록에서 사용자가 직접 선택한 tag, 수정 시각 |
| 운영 진단 | queue 깊이, 가장 오래된 event 나이, dead-letter 수 |

## 수집하지 않는 정보

다음 데이터는 plugin 요청, 서버 DB, 운영 로그에 저장하지 않습니다.

- prompt와 Codex 응답
- source code와 diff
- 전체 파일 경로와 workspace 경로
- 원본 명령, 인자와 환경변수
- transcript
- 도구 입력과 출력
- 원본 lifecycle hook payload
- OAuth token, cookie, 기기 token 원문, 연결 code

표시되는 프로젝트명은 `cwd` 전체가 아니라 마지막 폴더명만 최대 64자로 정제한 값입니다. 표시되는 명령은 원문이 아니라 `npm test`, `git status`, `Gradle test`, `코드 변경`, `기타 명령` 같은 고정 분류입니다. 원본 경로와 명령은 plugin의 event log와 queue를 만들기 전에 폐기합니다.

## 보호 방식

- GitHub OAuth에 state와 PKCE를 사용합니다.
- 인증 session과 기기 token은 원문이 아니라 hash로 저장합니다.
- 브라우저 변경 요청은 인증 cookie와 CSRF를 함께 검사합니다.
- 모든 사용자 데이터 조회는 로그인한 사용자의 소유권을 확인합니다.
- 중복·동시 요청은 idempotency key, DB lock, unique constraint로 방어합니다.
- production은 HTTPS, Secure `__Host-` cookie와 정확한 CORS origin을 강제합니다.
- 로그에는 body, query, cookie, Authorization, OAuth code를 기록하지 않습니다.

| 데이터 | 기준 |
|---|---|
| OAuth state·연결 code | 10분 |
| 웹 인증 session | 기본 168시간 |
| 기기 token hash·metadata | token 만료 90일 |

| 로컬 dead-letter | 최대 7일 |
| 운영 로그·암호화 backup | 최대 30일 |

## Discover 확장 시 적용할 기준

Discover는 인증된 API와 Hacker News·Remotive·DEV Community·Stack Overflow source, `/discover` 화면, 사용자별 저장 목록과 명시적 관심 기술 설정을 제공합니다. 화면은 server가 정제한 일반 text와 검증된 HTTPS 원문만 표시하며 외부 link에 `noopener noreferrer`를 적용합니다. DEV에서는 게시 글 ID·제목·설명·tag·게시 시각·예상 읽기 시간·반응 수·DEV HTTPS 원문만 정규화하고 작성자 프로필과 raw HTML·Markdown는 저장하지 않습니다. Stack Overflow에서는 question ID·정제한 제목·tag·게시 시각·score·평판 bounty·검증된 원문만 정규화하며 owner·본문·raw wrapper는 저장하지 않습니다. 저장할 때 browser가 보낸 카드 전체를 신뢰하지 않고 server cache의 normalized item을 다시 검증해 snapshot으로 보관합니다. 관심 기술은 20개 고정 목록에서 사용자가 직접 고른 최대 10개만 저장하며 방문·click 분석은 아직 수집하지 않습니다. 이후 확장도 다음 기준을 적용합니다.

- Server가 정해진 외부 API만 호출하고 사용자가 입력한 URL을 가져오지 않습니다.
- 외부 response 원문과 HTML은 저장·log하지 않고 길이가 제한된 일반 text와 검증된 link만 정규화합니다.
- Shared cache에는 정규화 item만 저장합니다. Freshness·maximum stale 기준은 Hacker News 10분·24시간, Remotive 6시간·72시간, DEV 30분·24시간, Stack Overflow 15분·24시간입니다. Cache row는 마지막 성공 갱신 후 최대 7일 안에 교체·삭제합니다.
- Task 32 전에는 Discover 방문·click 분석을 수집하지 않습니다.
- Pilot용 분석을 구현해도 fixed event 이름과 source·category만 저장하며 item ID·제목·URL·tag·검색어·선택 관심 기술은 수집하지 않습니다.
- 반복 방문을 계산하는 사용자별 분석 row는 90일 후 만료하고 내보내기와 계정 삭제에 포함합니다. 사용자 ID는 운영 log와 metric label에 남기지 않습니다.
- 개인화는 선택 관심 tag와 정제된 외부 item만 사용합니다. Prompt, AI response, code, diff, transcript, 원본 명령, tool input/output와 local path를 입력으로 사용하지 않습니다.
- Saved item snapshot과 관심 기술은 계정 소유 data로 처리해 내보내기 schema version 3과 계정 삭제 transaction에 포함합니다. 관심 기술을 모두 해제하면 row를 삭제합니다.

상세 계약은 [`ai/DISCOVER_CONTRACT.md`](./ai/DISCOVER_CONTRACT.md)를 따릅니다.

## 내보내기와 삭제

사용자는 자신의 데이터만 내보내거나 삭제할 수 있습니다. 계정 삭제는 관련 primary data를 하나의 transaction으로 지웁니다. 암호화 backup 사본은 장애 복구 목적으로만 최대 30일 유지된 뒤 만료됩니다.

서버는 사용자 PC의 plugin 파일을 원격 삭제할 수 없습니다. 계정 삭제 후 [플러그인 설치 가이드](./플러그인_설치_가이드.md)의 해제 절차를 함께 진행해야 합니다.

개발자가 확인해야 하는 endpoint별 상세 보안 계약은 [`ai/SECURITY_AND_PRIVACY.md`](./ai/SECURITY_AND_PRIVACY.md)에 있습니다.
