## 현재 제품 방향

AISideQuest는 개발자가 저장소를 내려받아 개인 PC에서 무료로 실행하는 방식을 기본으로 합니다. `npm.cmd run dev:local`이 PostgreSQL, migration·seed, API, 웹을 함께 준비합니다. 공개 서버 운영과 도메인 비용은 기본 사용 흐름에 포함하지 않습니다.

staging·production 배포 자동화와 파일럿 도구는 향후 팀 공유나 공개 서비스가 필요할 때 사용할 선택적 기능으로 보존합니다. 실제 운영 증거가 없으므로 기존 10명·7일 파일럿을 완료한 것으로 표시하지 않습니다. 상세 구현 이력은 [`ai/IMPLEMENTATION_PROGRESS_SUMMARY.md`](./ai/IMPLEMENTATION_PROGRESS_SUMMARY.md)에 보존되어 있습니다.

다음 제품 확장은 [`Discover 개발 계획`](./Discover_개발_계획.md)의 21~33번 작업입니다. Task 21~23에서 제품 계약, 공통 API와 안전한 Adapter·cache 기반을 만들었고, Task 24~25에서 Hacker News와 Remotive를 활성화했습니다. Task 26은 authenticated `/discover` 화면을, Task 27은 사용자별 저장 snapshot을, Task 28은 고정 allowlist 관심 기술과 결정적 정렬·추천 이유를 추가했습니다. Task 29A는 DEV 개발 글을, Task 29B는 Stack Overflow 미답변·평판 bounty를 추가했습니다. Task 30은 조건부 GitHub Issues adapter를 추가했고, Task 31은 Algora를 `NO-GO`로 문서화했습니다. Task 32는 개인정보 제한 analytics, source/cache/fetch metric, 30일 운영 dashboard와 warning/critical alert를 완료했습니다. 저장 snapshot·관심 기술·analytics는 내보내기와 계정 삭제에 포함되고 prompt·code·path 등 작업 content는 수집하지 않습니다. 다음은 Task 33 연속 7일 Discover 파일럿이며, Discover 구현과 기존 20번 운영 pilot 완료 판정은 분리합니다.
