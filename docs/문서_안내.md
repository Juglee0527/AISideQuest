## AI 개발 문서

AI용 상세 계약과 구현 이력은 [`docs/ai/`](./ai/README.md)에 있습니다. AI 에이전트는 코드 변경 전에 다음 문서부터 읽습니다.

- [`ai/CURRENT_STATE.md`](./ai/CURRENT_STATE.md): 현재 구현 상태와 남은 일
- [`ai/CODE_MAP.md`](./ai/CODE_MAP.md): 코드 위치와 책임
- [`ai/API_CONTRACTS.md`](./ai/API_CONTRACTS.md): API 공통 규칙과 endpoint 목록
- [`ai/README.md`](./ai/README.md): 작업별 읽기 순서와 문서 관리 규칙

> 사람용 문서는 사용 방법과 판단에 집중합니다. 정확한 상태 전이, DB 제약, DTO, 보안 matrix처럼 코드와 함께 유지해야 하는 내용은 AI 문서를 기준으로 관리합니다.

## 현재 상태

기본 제품 경로는 개발자가 저장소를 내려받아 `npm.cmd run dev:local`로 무료로 사용하는 로컬 실행입니다. 외부 staging·production 배포는 선택 사항이며 실제 인프라에는 연결하지 않았습니다. 자세한 범위는 [개발 현황](./개발_현황.md)을 확인하세요.
