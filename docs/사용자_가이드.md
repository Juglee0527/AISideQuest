# 사용자 가이드

## 시작하기

1. 저장소를 내려받고 [개발 및 실행 가이드](./개발_실행_가이드.md)에 따라 `.env`를 준비합니다.
2. `npm.cmd run dev:local`을 실행하고 `http://localhost:5173`에 접속합니다.
3. GitHub 계정으로 로그인합니다.
4. Codex에서 `AISideQuest 연결해줘`라고 요청하고 브라우저에서 승인합니다.
5. 여러 Codex 작업을 시작하면 홈에 실행 중인 작업별 카드, 경과 시간, 정제된 프로젝트명과 최근 명령 분류가 자동으로 표시됩니다.
6. Discover에서 수익 기회, 개발 소식과 커뮤니티 항목을 살펴봅니다.
7. 작업 중 개발 퀴즈를 풀고 제출합니다.
8. 최초 통과하면 100P가 적립되고 대시보드에 반영됩니다.

AISideQuest를 사용하는 동안 `dev:local` 터미널을 열어 둡니다. 별도 운영 서버나 유료 도메인은 필요하지 않습니다.

플러그인 연결 방법은 [플러그인 설치 가이드](./플러그인_설치_가이드.md)에 있습니다.

## 화면별 기능

| 화면 | 할 수 있는 일 |
|---|---|
| 홈 | 현재 실행 중인 모든 AI 세션의 상태·경과 시간·정제된 프로젝트명·최근 명령 분류, 오늘 작업 시간 확인 |
| 사이드 퀘스트 | 게시된 개발 퀴즈와 최근 응시 상태 확인 |
| 퀴즈 | 답안 선택, 자동 저장, 새로고침 복구, 제출 |
| Discover | 수익 기회·개발 소식·커뮤니티 항목 확인과 외부 원문 이동 |
| 대시보드 | 기간별 AI 작업 시간·퀘스트·포인트 확인 |
| 기기 | 브라우저 승인 연결, 연결 기기 확인, token 교체·폐기 |

## AI 작업이 자동으로 보이지 않을 때

1. Codex plugin이 활성화되어 있는지 확인합니다.
2. 기기 화면에서 연결 상태를 확인합니다.
3. 5초 정도 기다린 뒤 창을 다시 활성화합니다.
4. 계속 보이지 않으면 Devices에서 연결 상태를 확인하고 plugin을 다시 연결합니다. 홈에서는 실행 중인 Codex 작업을 보호하기 위해 시작·종료를 조작할 수 없습니다.

## 여러 AI 작업 확인

- 서로 다른 Codex 작업은 홈에서 각각 별도 카드로 표시됩니다.
- 각 카드에는 경과 시간, `진행 중` 또는 `확인 필요` 상태, 마지막 폴더명과 최근 명령 분류가 표시됩니다.
- `C:\Users\user\IdeaProjects\AISideQuest`는 `AISideQuest`로, 인자가 붙은 테스트 명령은 `npm test`처럼 표시됩니다.
- 상위 경로, 원본 명령·인자, 환경변수, 작업 내용과 프롬프트는 로컬 정제 단계에서 버리고 서버로 보내지 않습니다.
- 완료율은 작업 내용을 수집해야 정확히 계산할 수 있어 표시하지 않습니다. 현재는 서버가 확인한 시작 시각 기준 경과 시간을 제공합니다.
- ChatGPT 앱에서 작업을 강제로 중단하면 현재 Codex에는 전용 종료 훅이 없어 정상 완료로 즉시 표시하지 않습니다. 플러그인이 훅 호스트 종료를 확인하면 heartbeat를 멈추고, 서버가 마지막 heartbeat 이후 120초가 지난 세션을 `중단됨`으로 정리합니다.
- 지원 문의에는 발생 시각, 앱 버전, plugin 버전만 전달합니다. prompt나 코드는 보내지 않습니다.

서버나 네트워크가 잠시 끊겨도 plugin은 event를 로컬 queue에 보관하고 다시 전송합니다.

## Discover 사용

- Discover는 GitHub 로그인이 필요하지만 실행 중인 AI 작업은 필요하지 않습니다.
- 수익 기회, 개발 소식, 커뮤니티 탭에서 source가 정제한 항목을 확인할 수 있습니다.
- `마지막으로 확인된 정보` 안내는 source의 최신 갱신이 실패해 제한된 stale cache를 표시한다는 뜻입니다.
- 한 source가 일시적으로 실패하면 다른 source 항목은 계속 표시됩니다. 모든 source를 사용할 수 없을 때는 다시 시도할 수 있습니다.
- 급여는 외부 source가 실제 제공한 문구만 표시합니다. 급여 정보가 없다고 해서 description의 금액을 추정하지 않습니다.
- 원문 보기는 외부 사이트를 새 창에서 엽니다. 지원 조건, 게시 상태, 급여와 보상은 원문에서 다시 확인합니다.
- AISideQuest는 채용·계약·수익·보상 지급을 보장하지 않으며 Discover 조회와 원문 이동에 포인트를 지급하지 않습니다.

## 퀴즈와 포인트 규칙

- 퀴즈는 활성 AI 세션이 있을 때 시작할 수 있습니다.
- 선택한 답안은 서버에 저장되어 새로고침 후에도 복구됩니다.
- 정답은 서버에서만 채점합니다.
- AI 세션 종료 후 5분까지 진행 중인 퀴즈를 제출할 수 있습니다.
- 같은 퀘스트 버전은 최초 통과할 때만 100P를 받습니다.
- 베타 포인트는 현금 가치가 없고 환전·양도·구매할 수 없습니다.

## 내 데이터 관리

- 계정에서 내 데이터 사본을 요청할 수 있습니다.
- 최근에 다시 인증한 뒤 계정을 삭제할 수 있습니다.
- 계정 삭제 후에는 PC에 남은 plugin의 `device.json`, queue, dead-letter도 직접 삭제해야 합니다.

수집 범위와 보존 기간은 [보안 및 개인정보 안내](./보안_및_개인정보_안내.md)를 확인하세요.
